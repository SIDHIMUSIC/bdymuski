# Make a Wish — Browser Edition

A responsive, single-page browser adaptation of the original Pygame birthday animation. The original `make_a_wish.py` is intentionally preserved.

## Run locally

Open `index.html` in a modern browser, or serve the repository root with any static HTTP server.

## Deploy to Vercel

Import this GitHub repository into Vercel. No build command or framework preset is required; deploy it as a static site with the repository root as the output directory.

## Controls

- **Enter** — begin
- **Hold Space** — make the wish
- **R** — restart
- **F** — toggle fullscreen
- **Esc** — exit fullscreen (or restart when not fullscreen)
- **Touch** — tap to begin and press/hold to make the wish

No external assets, package installation, API keys, or build step are required.
